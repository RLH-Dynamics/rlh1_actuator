# Decision log

Add one record per real decision as a new markdown file in this folder (for example `YYYY-MM-DD-short-title.md`). Each record should include:

- **Date** — when the decision was made
- **Context** — the problem or constraint that forced a choice
- **Decision** — what was chosen
- **Consequences** — what follows, including what was deferred

Do not add a record until a decision actually exists. Open questions stay blank in [STATUS.md](../../STATUS.md).
