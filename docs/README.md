# Design notes

Architecture and design notes land in this folder. When Claude Code (or anyone else) dumps preliminary work here, sort it with a keep / revise / drop map: keep what is still useful, revise what needs correction, and drop what does not belong. A dump is not a result and not a decision. Record real decisions in `docs/decisions/`. Leave unknowns blank on the living board in [STATUS.md](../STATUS.md).
